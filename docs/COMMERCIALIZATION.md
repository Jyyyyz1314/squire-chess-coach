# 商业化发布门槛

以下事项在公开发布或收费前必须完成：

1. **确定项目许可证与商业模式。** 当前尚未添加项目级 `LICENSE`，这是刻意保留的产品决策，不代表可任意使用。
2. **履行第三方义务。** 分发 Stockfish WASM 时遵守 GPLv3，提供对应源码与许可证；棋子素材遵守其 GPL/BSD 声明。以 `THIRD_PARTY_NOTICES.md` 为起点做法律复核。
3. **账户与配额。** 不能让匿名用户无限消费共享模型密钥；加入登录、套餐、全局预算、账单告警和可关闭 AI 的运维开关。
4. **隐私与条款。** 告知用户哪些内容会发送给模型供应商，提供隐私政策、服务条款、数据删除与未成年人政策。
5. **可靠性。** 为模型供应商设置可观测性、熔断、超时、失败率告警和降级文案；不记录 API 密钥和完整私人棋谱。
6. **质量评测。** 建立固定棋局集，衡量讲解的合法性、与引擎一致性、教学价值、延迟和单次成本。
7. **数据迁移。** 为学习档案增加版本迁移器和损坏恢复，发布前验证旧版本导入。
8. **无障碍与兼容。** 完成键盘走子、屏幕阅读器标签、颜色对比、移动端与主流浏览器矩阵测试。

建议发布节奏：内部原型 → 小规模邀请测试 → 带账户与预算的付费测试 → 正式版。每个阶段均以 CI 全绿、依赖审计通过和备份恢复演练为准入条件。
